RO 倖存者油猴助手 v1.6.0

适配游戏：[RO Survivors](https://ro-survivors.com/)。资源核对日期：2026-11-16，公开版本 09c52f73（2026-11-15T21:48:42Z）。本版仅匹配新站，已移除原站域名。

**更新与安装**

从下方固定安装地址覆盖更新已有脚本，或在 Tampermonkey 中打开原来的脚本，用 ro-survivors-helper.user.js 的全部内容替换并保存，再刷新新站游戏。避免同时启用两个版本。脚本名称、namespace 和更新地址保持不变。

从旧站迁移：设置保存在各站自己的 localStorage，浏览器不会跨域自动带到新站。若要保留原配置，请在更新前到旧站助手的「匯入／匯出設定」点「匯出」，复制 JSON；更新后在新站粘贴并「匯入」，检查副本、4／5 技与宝箱偏好后再启动。若已经更新导致旧站不再显示助手，也可从本地保存的 JSON 导入，或在新站重新配置。游戏账号、角色和进度属于各站，助手不会迁移。

助手界面保留中文。新站支持繁体中文、英语、西班牙语和葡萄牙语：宝箱栏位会读取游戏当前的本地化名称，支持繁中「神祇」，选牌标题和远征按钮也兼容四种语言。游戏内切换语言后物品清单自动刷新。建议优先级使用「名称 [ID]」，可在切换语言或导入旧配置后保持匹配；纯名称需与新站的名称一致。

当前手牌可用时，优先读取游戏提供的技能／物品原始 ID；天赋把不同技能改成同名，或宝箱出现同名物品时仍能区分。手牌结构不匹配时才回到名称和图示识别，不使用旧组手牌覆盖当前牌面。

已按新站副本顺序更新末项为洛阳灯笼节；活动是否开放仍以游戏清单为准。旧版「迷宮森林」配置不会自动替换为其他副本，请重新选择。

首次安装：新建油猴脚本，删除默认内容后粘贴完整代码并保存。刷新游戏，点击右侧「RO Ⅱ」打开面板。按 F8 启动／暂停，F9 展开／收起。

悬浮入口「RO Ⅱ／RO ▶」和展开后的标题栏都可以按住拖动。位置自动保存在当前浏览器，刷新后恢复；窗口缩小时会自动限制在可见范围内。标题旁的「歸位」可恢复初始位置。点击入口仍是展开／收起，拖动不会误触展开。

若浏览器未执行脚本，参阅 [Tampermonkey 官方执行权限说明](https://www.tampermonkey.net/faq.php#Q209)。

**1. 指定副本重复远征**

展开「指定副本重複遠征」，选择副本，勾选「啟用自動重複遠征」。首次请站在远征队长附近，或手动打开游戏远征清单；「讀取遊戲副本清單」会读取真实副本名称和开放状态。

运行流程：结算画面等待 → 返回队长 → 选择指定副本 → 点击出发 → 沿用游戏当前的难度设置确认 → 下一局。胜利和死亡后都可以继续。默认局间等待 5 秒，自动开局次数 0 表示不限；也可以设置有限次数。计数从本次启用重复远征开始，刷新页面会重置计数。

脚本只自动确认单人远征的「前往野外」。副本未解锁、装备评分／职业／剧情要求不满足、组队提案或其他 NPC 对话会等待手动处理。它不会替你改难度、跳过前置剧情或选择其他角色。

返程时游戏会让角色回到队长附近。如果你手动离开队长，先走回来再继续；脚本不会在城内向其他 NPC 随意点击。

**2. 自动拾取掉落物**

「安全拾取掉落物」独立于宝箱选卡开关。支持经验宝石、金币、装备、卡片、宠物蛋、肉和磁铁。已经被游戏磁吸的物品会自行飞来，不再追逐。

安全可达的目标中，宝箱和磁铁属于同一最高优先级，二者按距离先近后远，再拾取其他掉落。大量近处的经验宝石不会把较远的宝箱或磁铁挤出候选列表。金钱不足的宝箱会略过；怪物附近的危险目标仍先避让，优先级不覆盖避怪规则。

脚本先评估怪物碰撞与地面预警，再选择拾取方向；较危险的掉落点会降低追逐优先级。寻路使用游戏原有的可通行检测与路径，不能穿墙或加速。拾取范围可在「走位、操作與診斷」调整。

普通掉落弹窗会等待原游戏的入场动画锁结束，再确认拾取。组队掉落分配默认「貪婪」，可以改成「需求」「放棄」或「等待手動」。该选项不代表保证获得组队物品。

避让是启发式判断，不能保证无伤；未涵盖所有特殊伤害、剧情机关和地图特例。掉落物追逐、避怪与宝箱寻路使用同一套路径风险评估。

**3. 技能数选择 4／5**

在「技能欄位（不含普攻）」勾选 4 或 5。脚本同时尊重本局实际可用栏位，不会额外添加技能栏。二转可以选择 5 个。

固定技能：火箭術 firebolt、冰箭術 coldbolt、雷擊術 lightning。导管自带的技能通过实际装备列表识别。

4 技模式再选一个额外技能，5 技模式再选两个。第四、第五技可以留空表示任意，也可以从技能列表选中文名称 [ID]。实际已经装备的额外技能会占用名额，防止学到第六个技能。切换为 4 技不会移除已经装备的第五技，仍可升级已拥有技能。

技能默认先比稀有度，再对三系法术比「目标 ＞ 急速／冷却 ＞ 伤害」。当前游戏还包含「優良」：完整顺序为傳說 ＞ 史詩 ＞ 稀有 ＞ 優良 ＞ 普通。取消「技能升級先比稀有度，再比目標／急速／傷害」后，技能先比较强化类型。此开关仅影响技能升级；宝箱固定先比配置优先级。额外技能未设置强化类型偏好，同品质时保持页面顺序。

面板顶部新增两个独立勾选：「允許局內技能重抽」和「允許寶箱重抽」，默认均开启。技能沿用旧版 skillReroll 设置；关闭其中一个不会关闭另一个。两者仍使用游戏共享的次数，并遵守保留次数和上限。关闭重抽后仍正常选牌和执行已启用的放逐；放逐本身带来的补牌使用放逐次数。

没有符合技能名额配置的牌时，仅在允许技能重抽时有限重抽整组；受重抽上限及保留次数限制。关闭后，若仍没有合规选项则等待手动选择，不会为了继续游戏而学入未配置的新技能。

**4. 已有技能放逐与多选排除**

展开「升級選牌前放逐已有技能」，有两个独立按钮：

- 「啟動放逐」：升级选卡时，先对牌面中的已拥有技能点击游戏的放逐按钮，再选择技能。没有学过的新技能不会被放逐。只有牌面上实际可操作的技能才能放逐，不会隔空修改名单或补充次数。
- 「啟用排除放逐的技能」：启用后，多选列表中勾选的技能不会被放逐。可以搜索中文名称或 ID。只勾选但没有启用此按钮时，名单不生效。

放逐一个已拥有技能意味着本局后续不再抽到它的升级。若希望继续升级三系法术，请勾选火箭術、冰箭術、雷擊術，并启用排除名单。默认放逐关闭，排除名单也关闭；不会因升级脚本就开始放逐。

放逐次数使用游戏原有次数；按钮无次数或不可用时继续正常选牌。关闭「自動選技能」时也不会执行这段选牌前放逐。

v1.2.0 新增「同時放逐普攻的升級牌」，默认勾选，但仍需启动放逐总开关才生效。识别当前真正装备的普攻 ID，普攻不计入 4／5 技名额。排除名单可勾选「普攻（所有武器）」统一保护各种普攻，也可以仅保护本局的特定普攻 ID。放逐的是升级机会，普攻本身仍正常攻击。

**5. 宝箱优先级中文显示**

从物品表选入后，文本框会显示例如：

```text
採集藥水 [p_pickup]
傷害藥水 [p_dmg]
```

每行一级，第一行为第一优先级，同级用 | 分隔。名称后保留的 ID 用于精确匹配，移动整行即可调整顺序。旧版纯 ID 自动补中文，不改变原有优先级。也接受完整名称或纯 ID。复杂、同名物品建议保留 [ID]。

例如药水：

```text
冷卻藥水 [p_cd] | 傷害藥水 [p_dmg]
範圍藥水 [p_area]
生命藥水 [p_hp]
```

三张都没有命中任一已配置栏位的第一行时，才使用重抽。单张只能刷新相同栏位，整组可以更换栏位。支持先单张后整组、反向、只单张、只整组或关闭；每箱默认最多重抽 6 次，可保留次数。

「允許寶箱重抽」关闭时不点击单张或整组重抽；打开后仍按上述方式执行。若下方方式选了「不重抽」，也不会重抽。批量连续开箱时，每个新宝箱分别计数；同一箱的重抽／放逐刷新不重置计数。

只要一张命中第一行就停止重抽。五个宝箱栏位统一先比较用户配置优先级，同级才比较稀有度；未配置或未匹配的物品排在所有已匹配级别之后。旧版的「稀有度優先」配置不会覆盖这项规则。

例如神格配置「貪婪之神 [g_avarice]」第一行、「智慧之神 [g_wisdom]」第二行：即使貪婪是普通，另有传说技能神格，也选貪婪。貪婪缺席且重抽次数用尽时，选智慧，再考虑未配置的神格。同一级写多个神格时，才在它们之间挑稀有度最高的。所有栏位留空时不重抽，直接选最高稀有度。

用尽重抽后默认选当前最优项，也可以等待手动。宝箱换装原有的翻牌确认会自动完成，当前物品可能被替换。

**6. 后台挂机**

勾选面板顶部「背景掛機：切換分頁繼續運行」并启动助手。该选项默认勾选，总开关未启动时不生效。切换到其他标签页后，自动选牌、避怪、拾取及重复远征继续执行。

启用时，助手将游戏当前的「离开页面自动暂停」设置设为关闭；关闭背景模式或暂停助手时恢复先前值。后台通过 Worker 大约每 50 毫秒驱动一次游戏原有的完整时钟，回到前台恢复原来的动画时钟，避免两套时钟同时驱动。不会改变角色速度或直接增加游戏时间。手动按 Esc 或暂停按钮造成的暂停会保留。

展开面板可以查看背景状态。显示「Worker 時鐘約 20 Hz」表示已接入后台驱动；若浏览器禁止 Worker，则改用普通计时器并显示可能限速的提示。浏览器会限制后台页面，普通计时器不能保证流畅。

后台挂机要求标签页仍在运行。浏览器冻结／丢弃标签页、关闭浏览器或电脑睡眠时，网页脚本无法继续执行。若切页后仍停止，可在浏览器的内存节省中为游戏添加始终保持活动的例外，并关闭会冻结页面的节能模式。不要关闭游戏标签页。

机制参考：[MDN 页面可见性与后台限速](https://developer.mozilla.org/en-US/docs/Web/API/Page_Visibility_API)、[Chrome 页面生命周期与冻结](https://developer.chrome.com/docs/web-platform/page-lifecycle-api)、[Chrome 节能模式冻结后台标签页](https://developer.chrome.com/blog/freezing-on-energy-saver)。

**7. 累积升级：前期及时、后期批量**

在游戏出发难度面板选择「累積」，然后在助手「累積升級：前期及時、後期批量」中设置策略。脚本不会在局内改写难度或强行切换模式；游戏选择「立即」时继续按原方式选牌。重复远征沿用游戏当前已选的难度与累积选项。

默认「智能」策略：

- 前 120 秒，或所选 4／5 技尚未填满实际技能栏时，有累积即点击游戏「升级」按钮。
- 成型后，升级和宝箱合计达到 5 次，或第一份累积已等待 30 秒，才打开整批。
- 生命低于或等于 45% 时提前打开；设置为 0% 可关闭此条件。

以上门槛均可调整。秒数按局内战斗时间计算，选牌、暂停或前台编辑设置的停顿不会凭空累加战斗时间。等待批量时继续原有避怪和拾取。

另有「批量」「每次累積立即處理」「手動按遊戲 B 鍵」三种策略。「批量」不采用前期／技能未成型条件，仍使用次数、等待上限和低血量条件；「手动」不自动打开累积，但你按 B 打开后，已启用的自动选卡仍工作。

游戏原生顺序是先宝箱、后技能，一次必须选完全部。智能策略调整开批时机，卡片数量和游戏动画照常。升级回血已经在升级发生时立即生效；低血量提前处理用于尽早获得强化，不会额外回血，也不能保证不会死亡。

组队只由队长打开；跟随队员等待队长。队列若含已关闭「自动选技能」或「寻宝与宝箱选卡」的类别，助手不自动打开整批，避免强迫你选择不希望自动操作的内容。暂停、死亡、过场或总开关停止时不会自动开批。死亡时尚未使用的累积仍可能丢失。

升級按钮未响应时不会连续重试；可手动按 B，或确认画面后点击助手「重新識別」。面板显示当前等待／开批原因，诊断 JSON 包含待选等级、宝箱数和两种重抽开关。

**8. 斐扬洞穴 Boss：月夜猫钟罩避难**

「走位、操作與診斷」新增「月夜貓鐘罩避難」，默认勾选，同时需要开启「自動避怪」和助手总开关。识别游戏钟罩效果的世界坐标及状态，不依赖繁中、英文或其他语言的提示文字。即使助手在钟罩出现后才接入本局，也可识别当前效果。

钟罩一出现就停止追宝箱、磁铁和其他掉落物，并暂停自动打开累积升级，优先通过游戏寻路进入钟罩内侧。进罩后，普通避怪候选路径限制在安全半径内，避免为了躲怪或追物品跑出罩外。钟声发动期间继续留在罩内，钟罩机制结束后恢复正常避怪、拾取及累积处理。后台模式开启时同样执行。

普通钟罩的当前倒计时为 9 秒。封印之钟的倒计时为 23 秒，需要在游戏要求的时限内击杀指定小王才会开启；封印未解除时，即使站在钟内仍会受到技能伤害。助手会进入钟下附近、停止追物并显示封印提醒，攻击继续由游戏自动施放；不会修改封印、攻击目标、伤害或保证限时击杀。

优先赶路可能仍会受到沿途怪物伤害；进罩后其他伤害也照常生效。路径不可达时会显示提示并等待手动走位。WASD／点击画面的手动接管、编辑设置、暂停助手和关闭避怪的规则仍然生效。诊断中新增钟罩位置、保护半径、封印状态及阶段信息。

**示例、操作与诊断**

「匯入／匯出設定」可导入包内 三系法术示例配置.json。示例设为 5 技，第四、第五技任意，宝箱偏好为冷却／伤害／双倍投掷／INT／三系神格；排除名单启用并保护三系法术，但放逐、重复远征和总运行开关都保持关闭。检查偏好后再启用对应功能。

WASD、方向键或点击游戏画面后，脚本让出控制 3 秒。前台编辑设置、游戏暂停、死亡或关闭功能时停止自动移动。后台模式开启后，切换标签页继续执行；关闭后台模式则切页停止自动操作。脚本不会替你复活或购买次数。

异常时展开诊断，点击「顯示診斷」。生成的 JSON 包含牌面、技能数、放逐配置、远征计数、背景时钟与模块状态，不包含密码或登录令牌。操作后页面未更新时会停止重复点击；确认页面后可用「重新識別」重新尝试，这会重置本组重抽计数。

当前在新站公开 HTML、真实选卡／累积升级方法、钟罩倒计时／伤害判定函数及模块翻译值构成的 DOM 测试环境中通过 104 项功能检查，以及发布构建和元数据检查。新增钟罩 X/Z 坐标、内圈边界、进罩优先级、原版 9 秒判定、封印解除／未解封对照、寻路不可达及后台运行检查；模型渲染、游戏状态、怪物和网络响应使用模拟数据。保留四语系选卡、重抽独立开关、批量升级、普攻放逐、重复副本及拖动位置检查。尚未在真实账号的 Tampermonkey 环境中完成实战联调。后续游戏更新或浏览器执行环境变化可能影响兼容性；脚本保留站点原有检测，不修改或屏蔽其检测及服务端校验。

配置保存在当前浏览器的站点本地存储；脚本只导入页面已引用的同源游戏模块，无外部脚本依赖。
