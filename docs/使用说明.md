RO 倖存者油猴助手 v1.2.0

适配游戏：[RO 倖存者](https://ro.hans-webgametw.com/)。资源核对日期：2026-11-15。

**更新与安装**

在 Tampermonkey 中打开原来的脚本，用 ro-survivors-helper.user.js 的全部内容替换并保存，再刷新游戏。继续使用原脚本的配置存储，已有宝箱优先级会保留；纯 ID 会显示成中文名称 [ID]。避免同时启用两个版本。

首次安装：新建油猴脚本，删除默认内容后粘贴完整代码并保存。刷新游戏，点击右侧「RO Ⅱ」打开面板。按 F8 启动／暂停，F9 展开／收起。

若浏览器未执行脚本，参阅 [Tampermonkey 官方执行权限说明](https://www.tampermonkey.net/faq.php#Q209)。

**1. 指定副本重复远征**

展开「指定副本重複遠征」，选择副本，勾选「啟用自動重複遠征」。首次请站在远征队长附近，或手动打开游戏远征清单；「讀取遊戲副本清單」会读取真实副本名称和开放状态。

运行流程：结算画面等待 → 返回队长 → 选择指定副本 → 点击出发 → 沿用游戏当前的难度设置确认 → 下一局。胜利和死亡后都可以继续。默认局间等待 5 秒，自动开局次数 0 表示不限；也可以设置有限次数。计数从本次启用重复远征开始，刷新页面会重置计数。

脚本只自动确认单人远征的「前往野外」。副本未解锁、装备评分／职业／剧情要求不满足、组队提案或其他 NPC 对话会等待手动处理。它不会替你改难度、跳过前置剧情或选择其他角色。

返程时游戏会让角色回到队长附近。如果你手动离开队长，先走回来再继续；脚本不会在城内向其他 NPC 随意点击。

**2. 自动拾取掉落物**

「安全拾取掉落物」独立于宝箱选卡开关。支持经验宝石、金币、装备、卡片、宠物蛋、肉和磁铁。已经被游戏磁吸的物品会自行飞来，不再追逐。

安全可达的目标中，宝箱和磁铁属于同一最高优先级，二者按距离先近后远，再拾取其他掉落。大量近处的经验宝石不会把较远的宝箱或磁铁挤出候选列表。金钱不足的宝箱会略过；怪物附近的危险目标仍先避让，优先级不覆盖避怪规则。

脚本先评估怪物碰撞与地面预警，再选择拾取方向；较危险的掉落点会降低追逐优先级。寻路使用游戏原有的可通行检测与路径，不能穿墙或加速。拾取范围可在「走位、操作與診斷」调整。

普通掉落弹窗会等待原游戏的入场动画锁结束，再确认拾取。组队掉落分配默认「貪婪」，可以改成「需求」「放棄」或「等待手動」。该选项不代表保证获得组队物品。

避让是启发式判断，不能保证无伤；未涵盖所有特殊伤害、剧情机关和地图特例。掉落物追逐、避怪与宝箱寻路使用同一套路径风险评估。

**3. 技能数选择 4／5**

在「技能欄位（不含普攻）」勾选 4 或 5。脚本同时尊重本局实际可用栏位，不会额外添加技能栏。二转可以选择 5 个。

固定技能：火箭術 firebolt、冰箭術 coldbolt、雷擊術 lightning。导管自带的技能通过实际装备列表识别。

4 技模式再选一个额外技能，5 技模式再选两个。第四、第五技可以留空表示任意，也可以从技能列表选中文名称 [ID]。实际已经装备的额外技能会占用名额，防止学到第六个技能。切换为 4 技不会移除已经装备的第五技，仍可升级已拥有技能。

默认先比稀有度，再对三系法术比「目标 ＞ 急速／冷却 ＞ 伤害」。当前游戏还包含「優良」：完整顺序为傳說 ＞ 史詩 ＞ 稀有 ＞ 優良 ＞ 普通。取消「稀有度優先」后，先比较强化类型。额外技能未设置强化类型偏好，同品质时保持页面顺序。

没有符合技能名额配置的牌时，可有限重抽整组；受重抽上限及保留次数限制。仍没有合规选项则等待手动选择。

**4. 已有技能放逐与多选排除**

展开「升級選牌前放逐已有技能」，有两个独立按钮：

- 「啟動放逐」：升级选卡时，先对牌面中的已拥有技能点击游戏的放逐按钮，再选择技能。没有学过的新技能不会被放逐。只有牌面上实际可操作的技能才能放逐，不会隔空修改名单或补充次数。
- 「啟用排除放逐的技能」：启用后，多选列表中勾选的技能不会被放逐。可以搜索中文名称或 ID。只勾选但没有启用此按钮时，名单不生效。

放逐一个已拥有技能意味着本局后续不再抽到它的升级。若希望继续升级三系法术，请勾选火箭術、冰箭術、雷擊術，并启用排除名单。默认放逐关闭，排除名单也关闭；不会因升级脚本就开始放逐。

放逐次数使用游戏原有次数；按钮无次数或不可用时继续正常选牌。关闭「自動選技能」时也不会执行这段选牌前放逐。

v1.2.0 新增「同時放逐普攻的升級牌」，默认勾选，但仍需启动放逐总开关才生效。识别当前真正装备的普攻 ID，普攻不计入 4／5 技名额。排除名单可勾选「普攻（所有武器）」统一保护各种普攻，也可以仅保护本局的特定普攻 ID。放逐的是升级机会，普攻本身仍正常攻击。

**5. 宝箱优先级中文显示**

从物品表选入后，文本框会显示例如：

```text
採集藥水 [p_pickup]
傷害藥水 [p_dmg]
```

每行一级，第一行为第一优先级，同级用 | 分隔。名称后保留的 ID 用于精确匹配，移动整行即可调整顺序。旧版纯 ID 自动补中文，不改变原有优先级。也接受完整名称或纯 ID。复杂、同名物品建议保留 [ID]。

例如药水：

```text
冷卻藥水 [p_cd] | 傷害藥水 [p_dmg]
範圍藥水 [p_area]
生命藥水 [p_hp]
```

三张都没有命中任一已配置栏位的第一行时，才使用重抽。单张只能刷新相同栏位，整组可以更换栏位。支持先单张后整组、反向、只单张、只整组或关闭；每箱默认最多重抽 6 次，可保留次数。

只要一张命中第一行就停止重抽，然后按排序规则选牌。默认稀有度优先：普通第一优先级与其他传说同时出现时，会选传说。取消「稀有度優先」后，宝箱先比配置优先级，同级再比稀有度。所有栏位留空时不重抽。

用尽重抽后默认选当前最优项，也可以等待手动。宝箱换装原有的翻牌确认会自动完成，当前物品可能被替换。

**示例、操作与诊断**

「匯入／匯出設定」可导入包内 三系法术示例配置.json。示例设为 5 技，第四、第五技任意，宝箱偏好为冷却／伤害／双倍投掷／INT／三系神格；排除名单启用并保护三系法术，但放逐、重复远征和总运行开关都保持关闭。检查偏好后再启用对应功能。

WASD、方向键或点击游戏画面后，脚本让出控制 3 秒。编辑设置、游戏暂停、死亡、切到后台或关闭功能时停止自动移动；后台也暂停自动界面操作。脚本不会替你复活或购买次数。

异常时展开诊断，点击「顯示診斷」。生成的 JSON 包含牌面、技能数、放逐配置、远征计数与模块状态，不包含密码或登录令牌。操作后页面未更新时会停止重复点击；确认页面后可用「重新識別」重新尝试，这会重置本组重抽计数。

当前通过 52 项功能测试，以及发布构建和元数据检查。包含真实选卡 UI 函数的入场锁、重抽、换装、技能及普攻放逐流程，以及 DOM 环境中连续两轮指定副本的完整状态转换。尚未在真实账号的 Tampermonkey 环境中完成实战联调。后续游戏更新或浏览器执行环境变化可能影响兼容性；脚本保留站点原有检测。

配置保存在当前浏览器的站点本地存储；脚本只导入页面已引用的同源游戏模块，无外部脚本依赖。

**GitHub 自动更新配置**

已按仓库 [rzj0506/auto-ro-survivors](https://github.com/rzj0506/auto-ro-survivors) 配置稳定更新地址。发布文件放在 userscript-release 分支：

- [脚本安装／下载地址](https://raw.githubusercontent.com/rzj0506/auto-ro-survivors/userscript-release/ro-survivors-helper.user.js)
- [版本元数据地址](https://raw.githubusercontent.com/rzj0506/auto-ro-survivors/userscript-release/ro-survivors-helper.meta.js)

上述远程地址要在首次发布成功后才能使用。本地脚本已经写好 @version、@updateURL、@downloadURL；仅下载聊天中的文件不会自动把仓库发布出来。

初次部署：把 GitHub自动更新发布包.zip 解压后的内容提交到仓库 main 分支，保留 .github/workflows/publish-userscript.yml。仓库保持公开，允许 GitHub Actions 工作流使用 contents: write 权限推送发布分支。无须把个人令牌写入脚本或仓库代码，工作流使用 GitHub 内置 GITHUB_TOKEN。

工作流成功后，从上方固定下载地址安装／更新一次已有脚本，并在 Tampermonkey 中保留自动更新检查。以后修改 src/ro-survivors-helper.user.js，同时递增 @version 与 const VERSION 后提交到 main，工作流会自动生成并发布正文和版本元数据。

浏览器会按油猴的检查周期拉取新版本，不保证发布后立即安装；也可以在油猴面板手动检查更新。安装新版本后刷新游戏页面，当前页面才会执行新代码。原来的本地配置保留。

如果希望由聊天助手直接推送，需先安装并连接 GitHub，允许访问该仓库；提供公开仓库链接只能让助手读取公开文件，不能赋予写入权限。

参考：[Tampermonkey 官方更新机制](https://www.tampermonkey.net/documentation.php?locale=en&q=update_url)、[GitHub Actions 内置认证](https://docs.github.com/en/actions/tutorials/authenticate-with-github_token)。
